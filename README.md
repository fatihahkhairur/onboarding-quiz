### Description
This is an interactive onboarding quiz built with **HTML, CSS, and JavaScript**. 
It helps simulate a “first week at a new job” scenario and provides feedback based on your answers.

The quiz demonstrates:
- DOM manipulation
- Dynamic question and answer rendering
- Progress bar and scoring system
- Quiz state management (start, quiz, result screens)
- Event handling for button clicks
- Responsive and simple UI design
